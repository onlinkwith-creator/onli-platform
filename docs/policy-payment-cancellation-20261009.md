# 중개·지급대행·지급보증 및 취소 약관 개정

## 변경 범위

- 문서 버전: `2026-10-09-v2`.
- 공통·기업·통역사 약관에 중개·지급대행·지급보증 역할을 명시한다.
- 행사별 업무 계약은 기업과 통역사 사이에 유지한다. 기업의 ON-LI 입금과 통역사의 실제 수령을 구분하고 법령상 직접 지급 의무를 우선한다.
- 실제 수행 보수와 지급해야 할 추가근무 보수는 마지막 수행일 다음 날부터 30달력일 이내 지급한다. 더 이른 법정·합의 기한을 우선하고 기업 미입금 시 ON-LI 자체 자금으로 지급한다.
- 정산은 관리자 확인을 유지한다. 자동 입금·지급·취소료 공제 기능을 추가하지 않는다.

## 기업 취소료

배정 확정 후 기업 귀책 취소에만 적용한다. 미수행 취소 부분의 사전 합의된 ON-LI 중개료를 기준으로 한다. 전체 기업 결제액과 통역사 보수에 비율을 적용하지 않는다.

| 취소 접수 시점 | 중개료 기준 상한 |
| --- | --- |
| 시작 14일 이상 전 | 0% |
| 7일 이상~14일 미만 전 | 20% |
| 48시간 이상~7일 미만 전 | 50% |
| 48시간 미만 전·당일·기업 노쇼 | 100% |

실제 청구액은 상한액과 증빙 가능한 순손해 중 적은 금액이다. 절감·회수된 비용과 회복된 손해를 반영하고 동일 부분의 정상 중개료·취소료·모집비를 중복 청구하지 않는다. 통역사의 법정 보수·휴업수당 등은 별도 판단한다.

취소 이메일 또는 의뢰 메시지 도달 시각을 기준으로 한다. 현지 업무 시작 시각과 실제 시간 차이를 사용하고 경계 시각은 낮은 요율에 포함한다. 부분 취소는 해당 배정·일정만 계산한다. 미확정 배정, 기업 귀책 없는 불가항력, ON-LI 또는 통역사 귀책 취소에는 기업 취소료를 부과하지 않는다.

통역사 취소·노쇼에는 고정 위약금을 부과하지 않는다. 실제 손해 주장과 수행 보수 지급을 구분하고 자동 공제하지 않는다. 환불은 공제액 확정 후 7영업일 이내이며 더 이른 법정 기한을 우선한다. 다툼 없는 반환액부터 확정·반환한다.

## 적용 전 확인

사용자의 배포 요청에 따라 운영 DB에 v2 원문 및 활성화 마이그레이션을 단일 트랜잭션으로 적용했다. 게시·시행 시각은 `2026-10-09 14:29:16.059637 UTC`다. v1 원문 해시와 게시·시행 시각은 보존됐다. 대응 프런트엔드는 이 변경 커밋을 main에 반영해 배포한다.

1. `20261009050000_policy_payment_cancellation_snapshot.sql`을 추가 적용한다. v1 스냅샷·시행 마이그레이션을 수정하지 않는다.
2. 실제 공개·시행 시각과 안내·동의 절차를 확정한다. 배포일이 달라지면 페이지 표시일과 버전을 함께 점검한다.
3. DB의 v2 내용 해시를 검증하고 공개·시행 상태를 활성화한 뒤 대응 프런트엔드를 배포한다. 미시행 v2 프런트엔드만 배포하면 새 동의 및 관련 제출이 거절되므로 단독 배포하지 않는다.
4. 기존 확정 업무의 비용·의무와 기존 동의 이력은 소급 변경하지 않는다.
5. 기업이 배정 확정 전에 자기 의뢰의 중개료 금액·일정별 배분을 확인하고 동의하는 운영 절차가 실제로 갖춰져야 한다. 아직 안내·동의되지 않았다면 새 취소료를 청구하지 않는다.

v2 SHA-256: `53da22727e7aa415977cec7bbfad293237b1a270abd756526a1a605f67117f9b`.

스냅샷 생성기는 새 파일만 생성하며 기존 파일 덮어쓰기를 거부한다:

```sh
node scripts/generate-policy-snapshot.mjs --output <new migration filename.sql>
```

## 법률 검토 한계

한국법을 준거법으로 하되 적용 가능한 일본 등 업무 수행 국가의 강행법규와 법정 권리를 배제하지 않는다. 취소율은 법정 요율이나 적법성 보장이 아니다. 약관 개정은 직업소개 등록·허가, 중개료 규제, 지급대행·세무 또는 실제 근로관계 판단을 대신하지 않는다.

국가법령정보센터 확인 기준: 2026-10-09. 관련 근거는 [민법 제398조](https://www.law.go.kr/법령/민법/제398조), [약관규제법 제8조](https://www.law.go.kr/법령/약관의규제에관한법률/제8조), [근로기준법 제20조](https://www.law.go.kr/법령/근로기준법/제20조)다. Legalize-KR 전용 도구가 이 세션에 없어 공식 법령정보센터를 직접 확인했다.
